### Critical Issue — All Tests Failing

All 5 in-scope test suites fail with:

```text
Error: Cannot find module
  '/@id/C:/GitHub/.../client/vitest.setup.ts'
```

Root cause: `vite.config.ts` sets `root: "client/"` and
`setupFiles: ["./vitest.setup.ts"]`. Vitest resolves setup files
relative to the Vite root, producing `client/vitest.setup.ts` — but
the file lives at `vitest.setup.ts` (repo root).

**Fix** (one of two options):

Option A — update `setupFiles` path:

```ts
// vite.config.ts line 102
setupFiles: ["../vitest.setup.ts"],
```

Option B — move the file:

```bash
mv vitest.setup.ts client/vitest.setup.ts
```

Option A is lower risk (no file moves, no git history disruption).

### Duplicate Test File

`client/src/utils/seo-helpers.test.ts` is a duplicate of
`client/src/utils/__tests__/seo-helpers.test.ts`. The root-level
copy is outside the `include` glob
(`src/**/__tests__/**/*.{test,spec}.{ts,tsx}`) so it is never run,
but its presence is confusing. Delete it.
