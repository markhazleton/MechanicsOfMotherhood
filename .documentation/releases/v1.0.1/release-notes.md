## Highlights

This is a maintenance patch release focused on SEO correctness.
All internal URLs and structured data now consistently use trailing
slashes, eliminating 301 redirect chains that were degrading crawler
efficiency and link equity on `mechanicsofmotherhood.com`.

Additionally, the project tooling was migrated from `.specify/` to the
expanded `.devspark/` framework, bringing in new scripts, templates,
and a skills registry. `CLAUDE.md` and `agents-registry.json` were
added to support AI-assisted development workflows.

## Bug Fixes

- **Trailing slash in breadcrumb hrefs** — `seo-helpers.ts`
  `generateBreadcrumbs()` was emitting `/recipes`, `/blog`, and
  `/categories` without trailing slashes, causing 301 redirects on
  every breadcrumb click.
- **Trailing slash in prerender structured data** — `prerender.js`
  BreadcrumbList `item` fields for `/recipes` and ItemList `url`
  fields for `/recipe/<slug>` were missing trailing slashes in
  pre-rendered JSON-LD blobs.
- **Blog structured data URL** — `generateBlogStructuredData()` emitted
  `${SITE_CONFIG.url}/blog` without trailing slash; corrected to
  `.../blog/`.
- **Canonical URL for recipe pages** — `prerender.js` `canonical`
  variable used `/recipe/${slug}` as `@id`, `url`, and
  `mainEntityOfPage`; corrected to `/recipe/${slug}/`.
